# Laurent de Laroche Souvestre

**Digimax Ltd** · *Every format. One studio.* · [digimax.mu](https://digimax.mu)

I build software that runs in real rooms: indoor cycling studios, museum installations, VR labs and the small businesses behind them. Mostly web apps on Cloudflare, Android and Windows apps where hardware is involved, and Unity for XR.

### What I'm working on

- **Grannygear studio system.** Ride app for Android tablets back to Chrome 81, a Windows app, a studio TV screen and an Android bridge that speaks ANT+ and Bluetooth to trainers, power meters, heart-rate straps and Zwift Click controllers. Private; built for a working studio in Cape Town.
- **Museum show control.** Projection, audio and BrightSign playback for installations at Iziko Museums, including a 310° cylindrical projection wall and an Electron controller that replaces a Q-SYS core.
- **XR and haptics.** Unity on Quest 2/3 with Haply Inverse 3 haptics for dental training research at the UWC Immersive Zone.
